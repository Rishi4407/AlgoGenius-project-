## 🧭 The 4-Year Curriculum & Career Progression

### 📘 Year 1: Fundamentals & Communication
*Focus: Mathematical bedrocks, discrete logic, systems fluency & professional scientific expression.*
- **Semester 1: Mathematical Foundations & Computational Logic**
  - `MTH-101`: Linear Algebra & High-Dimensional Vector Spaces (5 Credits)
  - `CS-101`: Principles of Computing, Linux Systems & Version Control (5 Credits)
  - `MTH-102`: Discrete Mathematics & Formal Logic for AI (5 Credits)
  - `COM-101`: Technical Communication, Scientific Writing & AI Rhetoric (5 Credits)
- **Semester 2: Continuous Optimization & Ethical AI Discourse**
  - `MTH-103`: Multivariable Calculus & Continuous Optimization (5 Credits)
  - `MTH-104`: Probability Theory & Stochastic Processes (5 Credits)
  - `CS-102`: Object-Oriented Programming & Computational Thinking in Python (5 Credits)
  - `PHI-101`: Ethics, Algorithmic Bias & Societal Governance of AI (5 Credits)
- **Annual Milestone**: *The First-Year Foundations Portfolio & Freshman Colloquium* (Authoring a computational linear algebra library in C/Python + 10-page LaTeX research synthesis).

---

### 💻 Year 2: Programming & Data Science Foundations
*Focus: Programmers and Data Science foundations, algorithms, and high-performance Python development.*
- **Semester 3: Data Structures, Advanced Algorithms & Vector Systems**
  - `CS-201`: Data Structures & Algorithmic Analysis (CLRS) (5 Credits)
  - `CS-202`: Advanced Python Engineering & High-Performance Computing (5 Credits)
  - `DS-201`: Relational, Distributed & Vector Database Systems (pgvector, Chroma) (5 Credits)
  - `DS-202`: Exploratory Data Analysis, Visualization & Scientific Wrangling (5 Credits)
- **Semester 4: Classical Machine Learning & Algorithmic Optimization**
  - `ML-201`: Statistical Machine Learning: Supervised Foundations (5 Credits)
  - `ML-202`: Ensemble Methods, Decision Trees & Gradient Boosting (XGBoost/LightGBM) (5 Credits)
  - `CS-203`: Dynamic Programming, Greedy Algorithms & NP-Completeness (5 Credits)
  - `ML-203`: Unsupervised Learning, Clustering & Dimensionality Reduction (5 Credits)
- **Annual Milestone**: *The Algorithmic Benchmark & Kaggle Debut* (Custom HNSW vector database + top 10% competitive machine learning benchmark placement).

### 🚀 Year 3: AI Projects, Annual Exhibition & Industry Networking
*Focus: Deep Learning architectures, working capstones, public demo day, and senior industry mentorship.*
- **Semester 5: Deep Learning Architectures, Transformers & MLOps**
  - `DL-301`: Deep Learning Fundamentals & PyTorch Framework Mastery (5 Credits)
  - `DL-302`: Transformers, Large Language Models & Attention Mechanisms (5 Credits)
  - `SYS-301`: Production MLOps, Containerization & High-Throughput Serving (FastAPI, Docker, TensorRT, Triton) (5 Credits)
  - `CAP-301`: Capstone Incubation & Research Methodology (5 Credits)
- **Semester 6: Capstone Project Execution & The AlgoGenius Innovation Expo**
  - `CAP-302`: Advanced AI Capstone Engineering & System Hardening (8 Credits)
  - `EXP-301`: The AlgoGenius AI Innovation Expo & Demo Day Presentation (6 Credits)
  - `NET-301`: Industry Networking, Mentorship & Corporate Partnerships (6 Credits)
- **Annual Milestone**: *The Annual AlgoGenius AI Innovation Expo* (Live working demonstrations at physical booths, public defense before a Silicon Valley jury, and seed grants).

### 🎯 Year 4: Tech Placement & Industry Launch
*Focus: High-stakes interview prep (algorithms, ML systems design, theory), on-campus recruitment, and senior thesis.*
- **Semester 7: Large-Scale AI System Design & Interview Intensive**
  - `INT-401`: Advanced Algorithmic & Data Structures Interview Bootcamp (Hard LeetCode) (6 Credits)
  - `SYS-401`: Large-Scale Machine Learning System Design (Recommenders, LLM clusters) (6 Credits)
  - `ML-401`: Machine Learning Theory & Deep Learning Bar-Raiser Defense (Whiteboard proofs) (4 Credits)
  - `CAR-401`: Behavioral Leadership, STAR Framework & Negotiation (4 Credits)
- **Semester 8: The Placement Drive, Senior Thesis & Tech Launch**
  - `PLC-401`: AlgoGenius Corporate Placement Drive & On-Campus Recruiting (8 Credits)
  - `THE-401`: Senior AI Research Thesis & Public Oral Defense (8 Credits)
  - `ALU-401`: AlgoGenius Alumni Fellowship & Lifelong Mentorship Induction (4 Credits)
- **Annual Milestone**: *Secured Tier-1 Offer Letter / Research Fellowship + Public Thesis Defense + Induction into the Global Alumni Network*.

## ⚡ Interactive Portal Capabilities

1. **Dean's Orientation & Convocation Dispatch**: Authentic welcome address, Director's Charter, 4 Academic Pillars, and the 5 Cardinal Rules for Freshman Year with an interactive audio player simulator.
2. **Interactive Semester Navigator**: Expandable course syllabi detailing credit hours, weekly commitment, core competencies, instructional modules, mandatory lab projects, and recommended textbooks.
3. **Personal Study Progress Tracker**: Real-time progress bar and local-storage persistent checkboxes to mark completed courses.
4. **Year 3 Capstone Exhibition Vault**: Interactive gallery of student-engineered systems across Healthcare, Robotics, Generative AI, and Quantitative Finance with booth locations, awards, and mentors.
5. **Year 4 Placement Matrix & Mock Interview Bank**: Placement partner breakdown (Google DeepMind, OpenAI, NVIDIA, Meta, Tesla, Jane Street, Microsoft Research) paired with an interactive question bank featuring algorithmic solutions, system design diagrams, and theory breakdowns.
6. **Curated Open Research Library**: Searchable and filterable archive of seminal AI papers (*Attention Is All You Need*, *ResNet*), university lecture series (Stanford CS229, MIT 6.006), textbooks, and GitHub repositories.
7. **AI Readiness Diagnostic Compass**: 5-pillar interactive evaluation calculating student readiness score and recommending targeted academic steps.
8. **One-Click Syllabus Exporter**: Generates and downloads a complete plain-text / markdown curriculum document for offline tracking.

## 🛠️ Tech Stack & Architecture

- **Frontend Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **State Persistence**: Browser `localStorage` for curriculum completion tracking
- **Design Philosophy**: Zero-pill discipline, WCAG AA compliance, editorial typography (*Plus Jakarta Sans* & *JetBrains Mono*), responsive desktop-to-mobile baseline.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/your-username/algogenius-ai-roadmap.git

# 2. Navigate to the project directory
cd algogenius-ai-roadmap

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Visit `http://localhost:3000` to access the portal.

### Production Build
```bash
# Validate TypeScript and build bundle
npm run build

# Preview production build locally
npm run preview
```
